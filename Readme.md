# DEUTSCH 🇩🇪

**OSINT** ist ein leistungsstarkes, terminalbasiertes Open Source Intelligence Tool und wandelt sie in ein interaktives, mehrsprachiges Kommandozeilen-Interface um. 

## 🚀 Installation & Start

Befolge diese Schritte, um das Tool herunterzuladen und zu starten:

1. **Repository klonen**

   git clone https://github.com/Lorik1409/OSINT.git

2. **In das Projektverzeichnis wechseln**

   cd OSINT

3. **Abhängigkeiten installieren**

   pip install -r requirements.txt

4. **Tool starten**

   python main.py
